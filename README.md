# دوره آموزشی عرفان — Student Platform

نسخه پایه پروژه پلتفرم دانش‌آموزی برای erfantooltips.ir.

ساختار هدف:
- /login — ورود دانش‌آموز
- /register — ثبت‌نام
- /panel — پنل دانش‌آموز
- /wp-admin — مدیریت سایت

این پروژه مستقل از Woodmart طراحی می‌شود و برای اتصال به احراز هویت بومی WordPress و دسترسی خصوصی به دوره‌ها و کلاس‌های BigBlueButton آماده است.
