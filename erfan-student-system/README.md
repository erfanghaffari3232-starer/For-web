# Erfan Student System

افزونه واقعی وردپرس برای سیستم دانش‌آموزی سایت دوره آموزشی عرفان.

## نصب
1. پوشه `erfan-student-system` را به صورت ZIP فشرده کنید.
2. در وردپرس از مسیر افزونه‌ها → افزودن → بارگذاری افزونه نصب کنید.
3. افزونه را فعال کنید.
4. افزونه سه صفحه می‌سازد: ورود دانش‌آموز، ثبت‌نام دانش‌آموز و پنل دانش‌آموز.

## BigBlueButton
نسخه اول ساختار پنل را آماده می‌کند؛ لینک واقعی کلاس باید بعداً برای هر دوره/دانش‌آموز به شکل امن اضافه شود. هیچ API Secret یا رمز سرویس در این مخزن قرار نمی‌گیرد.
